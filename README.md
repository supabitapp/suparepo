# Suparepo

A monorepo for Supaimg and Supabit apps.

- Marketing websites
- Tauri desktop app

The [Supacode website source](https://github.com/supabitapp/supacode/tree/main/apps/supacode.sh) lives in the Supacode app repository.

## Stack

- Turborepo
- Bun
- Tauri
- React with TailwindCSS/Shadcn UI
- NextJS
- Oxc for linting and formatting
